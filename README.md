# 🧪 Rick and Morty Fan Site

Сайт-визитка по мультсериалу «Рик и Морти», написанный на чистом HTML, CSS и JavaScript. Без библиотек, без фреймворков — только база.

## 🔥 Что умеет

- 🎲 **Случайные цитаты** — при каждом клике выпадает новая фраза Рика
- 🔢 **Счётчик кликов** — считаем, сколько раз ты спас вселенную
- 🥚 **Пасхалка** — на каждом 7-м клике Рик начинает трястись (потому что 7 — счастливое число)
- 🌈 **Все цитаты** — кнопка, которая выводит все фразы по очереди с разными цветами (цикл `for` в действии)

## 🛠 Технологии

- HTML5
- CSS3 (анимации, transitions, flexbox)
- Vanilla JavaScript (addEventListener, массивы, циклы, условия)

## 🎯 Чему я научился делая этот проект

- Работать с DOM: находить элементы и менять их на лету
- Использовать `addEventListener` для обработки кликов
- Писать условия и циклы
- Делать CSS-анимации и перезапускать их через `void offsetWidth`
- Искать и чинить баги в своём коде
